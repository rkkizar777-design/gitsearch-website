Not another GitHub client.
A better one.

GitSearch started because the official GitHub app doesn't let you do half the things you'd want on mobile. So I built one that does.

It searches repos, shows you beautiful READMEs, has an APK store where you can actually download and install apps from GitHub releases, lets you chat with other devs, follow people you care about, and keeps your exploration history private.

Zero login for basics. Search and browse without an account. Sign in with GitHub for chat, following, and personalized recommendations. Your data stays on your device.

What's new

Recent updates and fixes

v1.0.0.43Aug 2026

Update checker & APK Store fixed

  • Update checker now works — was always showing error even when API succeeded
  • APK Store search no longer empty — rate limiting handled with wait-and-retry
  • Shared rate limit state between all API layers
  • ForYou queries reduced to prevent burning through rate limits
v1.0.0.42Aug 2026

Complete API hardening

  • All fetches now have 40s timeout and 3 retries with exponential backoff
  • Rate limit errors no longer crash — now wait and retry properly
  • Empty results never cached — stale broken data auto-cleared on upgrade
  • README always loads with 3 independent retries and stale cache fallback
v1.0.0.41Aug 2026

README & search fixes

  • README now loads on Android — bypasses blocked raw.githubusercontent.com
  • Search 401 errors fixed — broken proxy URL no longer injected
  • Expired tokens auto-clear and retry without auth
v1.0.0.40Aug 2026

GitStore browsing restored

  • CapacitorHttp disabled — was intercepting all fetch() calls
  • GitStore now actually loads repos and shows APK releases
  • Stale date filters updated for 2026
v1.0.0.39Aug 2026

APK Store & download plugin

  • Native APK download plugin for direct install from GitHub releases
  • GitStore browsing with search, categories, and bookmarks
  • Version picker showing all available APK releases
